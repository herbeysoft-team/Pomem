🧾 POMEM 2.0 — Polar Memorandum Management System
📌 Overview

POMEM (Polar Memorandum) is an internal utility software developed for Polar Petrochemicals Limited to digitize and streamline the process of raising, tracking, and approving memos, eliminating paper-based workflows.

Version 2.0 introduces major upgrades such as:

Mobile-first architecture (React Native + Expo)

Real-time push notifications

Improved speed and pagination

Secure backend API (Express.js)

Optimized user interface and role-based access control

🚀 Features

✅ Create, edit, approve, and track memos digitally
✅ Role-based user access and department-level routing
✅ Push notifications and email alerts for updates
✅ Mention feature (@username) to notify users in discussions
✅ Real-time activity overview dashboard
✅ Mobile notification badge and custom sound alerts

📱 Mobile App Special Features

Instant push notifications (via FCM integration)

Notification badge updates on app icon

Optimized for on-the-go memo actions

Syncs seamlessly with the web app backend
